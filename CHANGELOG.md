# Changelog

## v1.0.0

- Established the supported Home Status v1 runtime and presentation model.
- Finalized the coordinated NOW, RECENT, AWARENESS, and VISUAL transport
  channels and the included dashboard card.
- Uses Recorder-backed recent activity and integration-owned semantic
  interpretation for selected household information.
- Includes configurable lanes, ticker-only layouts, Visual Center media,
  light/dark/auto appearance, and tablet-focused performance safeguards.
- Removed obsolete pre-v1 architecture, compatibility paths, and development
  artifacts from the public repository.
